# Conversational Group Food Recommender System
Web-based conversational group food recommender system developed for a Bachelor's thesis at the Univsersity of Regensburg.

## Study
Influence of different Aggregation Strategies on perceived Fairness and Satisfaction
in conversational Group Food Recommender Systems

Author: Maximilian Schnabel
Supervisor: Prof. Dr. David Elsweiler

## Tech Stack
- Python / Flask
- PostgreSQL
- Deployed on Render.com

## Setup
install: pip install -r requirements.txt
start: python app.py
